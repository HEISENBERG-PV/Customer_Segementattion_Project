# 🧠 Customer Segmentation using K-Means + Streamlit

An end-to-end Machine Learning project that segments customers into meaningful groups using K-Means clustering and provides an interactive UI built with Streamlit.

---

## 🚀 Project Overview

This project analyzes customer behavior and groups them into clusters such as:

- 🟢 Daily Customers  
- 🟡 Weekend Customers  
- 🔴 Promotion Customers  

It helps businesses understand user behavior and perform targeted marketing.

---

## 🧠 Tech Stack

- Python  
- NumPy  
- Pandas  
- Scikit-learn  
- Streamlit  
- Pickle  

---

## 📊 Features Used

- Age  
- Average Time Spent  
- Visits per Week  
- Promotion Interest  

---

## ⚙️ How It Works

1. Data is preprocessed and scaled  
2. K-Means clustering is applied  
3. Model is trained and saved using pickle  
4. Streamlit UI takes user input  
5. Model predicts the cluster of a new customer  

---

## 🖥️ Streamlit UI

The app allows users to input their details and instantly get their customer segment.

---

## 🎯 Use Cases
1. Customer targeting
2. Personalized marketing
3. Business analytics
4. E-commerce insights
